# Changelog

Everything that changes on a surface partners depend on: the backend API, the
deep-link contract, the callback payload, and the Yanez mobile apps.

Entries are tagged by surface — **Backend API**, **iOS**, **Android**, **Web**,
**Docs** — and anything that can break a working integration is additionally
tagged **Breaking**. Use the category links in the sidebar to filter.

!!! tip "Watch for breaking changes"

    Subscribe to this repository on
    [GitHub](https://github.com/yanez-compliance/yanez-yid-partner-docs) to be
    notified when a **Breaking** entry lands.
